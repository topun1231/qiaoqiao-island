# 敲敲岛 · Windows 单机版

陪小熊在小岛上练习打字：12 关冒险、无限随机的全字母接果子，以及警察抓小偷。

当前版本为 2.7.1（2026-10-16）；主线印章全关复查通过，修复重玩时地图隐藏印章。源码与本版 Windows 单机包同步发布，下载入口见下方。

## 下载游玩

1. 登录有权访问本私有仓库的 GitHub 账号，打开 [最新单机包](https://github.com/topun1231/qiaoqiao-island/releases/latest)。
2. 下载附件 `qiaoqiao-island-windows.zip`，完整解压。
3. 双击文件夹中的 **敲敲岛.exe**，游戏会在默认浏览器中打开。

下载完成后，游玩不需要网络、账号、Node.js 或 Python。需要 Windows、内置 .NET Framework 4.x、支持 WebGL2 的桌面浏览器和实体键盘。请切换英文输入。

请保持 exe 与 dist 文件夹在一起；不要在压缩包中直接运行。结束后可在系统托盘右键“敲敲岛”，选择退出。

## 当前玩法

- 12 关冒险，每关 3 段；地图可自由选关或继续最近未完成的一关。
- 石头过河：大石头路跳得多、短码较短；小岛捷径跳得少、短码较长，中途小岛可以换路，两种路线同等完成。
- 第 5 关：在林间岔路输入 2、3、4 字母混合短码，沿小径寻找朋友。可以绕路，死路必须自行返回；走过的小径留下脚印。
- 第 6 关：同一张林间地图先找齐蜂蜜和果汁，再去野餐地；逐段使用 3、3、4 字母短码，可任选采购顺序，过段和刷新保留位置与篮中食物。
- 第 8 关：用 3/3/4 字母混合短码拿取与分类摆放；绿色“已放好”、橙色“需调整”和未整理标签明确区分。放错自行搬回，后两段根据用途判断。
- 第 9 关：看物品线索挑对应词卡，用 3/3/4 字母混合短码选择，再写完整单词；原有单词与题量保留。
- 第 11 关：自选拜访顺序，用混合短码到朋友家，按朋友心愿挑邀请，再写完整句子；朋友收到后去野餐地。
- 主线每关两枚挑战印章：完整三段不求助、零错按。历史最佳、印章在本地保存；原结算直接显示，没有新增奖励弹窗。
- 第 12 关：用 3/4/4 字母混合短码移球击球、按变化图样搭塔、绕云收集五颗星；选错或走错需要自行调整。
- 入场只认识最多三个未练键，游戏中及换段不再弹出认键练习；可主动点“要提示”。
- 地图底部“自由开玩”：接果子与警察抓小偷两张场景卡片，点击直接进入。
- 警察抓小偷：三档速度，连续随机全字母输入，连对加速，追上获胜；小偷先到藏身处则失败。字母条紧邻角色，错字改对继续，Esc 暂停。当前局刷新后重新开始。
- 全字母接果子：A–Z 随机出果，轻松 / 进阶 / 挑战三档速度；接齐 26 个字母后继续出果。
- 连击、短连击目标、各速度独立的本地最高纪录，以及可关闭并记住选择的轻音效。

## 存档

游戏固定在 `http://127.0.0.1:4173/` 运行，进度和纪录保存在当前浏览器的网站数据中。本仓库和下载包不包含个人存档。已开始的旧局按原玩法续玩。第 5、6、8、9、11、12 关开场提供“重玩本关，体验新版玩法”；也可从暂停菜单重玩。本关重新开始，已完成记录、其他关卡进度与接果子纪录保留。换电脑、换浏览器或清除网站数据不会自动迁移进度；请使用原来的浏览器，避免隐私窗口。

## 源码与测试

`dist/` 就是可运行的源码和资源，不需要前端构建。`dist/game/` 是当前冒险入口，`dist/fruit-challenge/` 是正式接果子模式，`dist/chase/` 是警察抓小偷。旧 v8、preview、challenge-test 和两套接果子试玩已清理；仅保留当前正式模式、共用资源和存档兼容代码。`engine-classic.js` 保留其他关卡逻辑和旧存档续玩及第 6、8、12 关的分版本规则，`engine-v3.js` 保留更早存档兼容；它们不是独立旧版入口。

- `desktop/Launcher.cs`：Windows 启动器源码。
- `desktop/build.ps1`：使用 Windows .NET Framework 编译器重新生成启动器。
- `tests/`：自动测试与测试用夹具。
- `dist/vendor/`：随包提供的 Three.js 及其 MIT 许可证。

开发者安装 Node.js 后，在仓库根目录运行：

```powershell
npm test
```

没有 npm 依赖，不需要运行 `npm install`。重新编译启动器时运行：

```powershell
powershell -ExecutionPolicy Bypass -File desktop/build.ps1
```
