# 敲敲岛 · Windows 单机版

陪小熊在小岛上练习打字：12 关冒险、自由练习，以及无限随机的全字母接果子。

## 下载游玩

1. 登录有权访问本私有仓库的 GitHub 账号，打开 [最新单机包](https://github.com/topun1231/qiaoqiao-island/releases/latest)。
2. 下载附件 `qiaoqiao-island-windows.zip`，完整解压。
3. 双击文件夹中的 **敲敲岛.exe**，游戏会在默认浏览器中打开。

下载完成后，游玩不需要网络、账号、Node.js 或 Python。需要 Windows、内置 .NET Framework 4.x、支持 WebGL2 的桌面浏览器和实体键盘。请切换英文输入。

请保持 exe 与 dist 文件夹在一起；不要在压缩包中直接运行。结束后可在系统托盘右键“敲敲岛”，选择退出。

## 当前玩法

- 12 关冒险，每关 3 段；地图可自由选关或继续最近未完成的一关。
- 石头过河：大石头路跳得多、短码较短；小岛捷径跳得少、短码较长，中途小岛可以换路，两种路线同等完成。
- 森林找朋友：可回头、绕路的多岔路网，走过的小径留下标记；可以找围巾、遇见松鼠。探索不计错。
- 野餐采购：自选先取蜂蜜还是果汁，带着第一份取齐第二份，再送到朋友身边；移除重复的假岔路。
- 房间改造：按阅读、表演等用途安排书、灯、软垫和玩具，左右两边均可组成有效布局；试摆不算打字错误。
- 野餐活动：滚球、积木、风筝及梨、果汁、蛋糕分别对应所选伙伴，输入文字和画面一致。
- 自由练习涵盖不同字母组合、全字母及其他练习内容。
- 全字母接果子：A–Z 随机出果，轻松 / 进阶 / 挑战三档速度；接齐 26 个字母后继续出果。
- 连击、短连击目标、各速度独立的本地最高纪录，以及可关闭并记住选择的轻音效。

## 存档

游戏固定在 `http://127.0.0.1:4173/` 运行，进度和纪录保存在当前浏览器的网站数据中。本仓库和下载包不包含个人存档。已开始的旧版第 4、5、6、8、12 关会按原玩法续玩；从暂停菜单选择“重新玩这关”可体验新路线。换电脑、换浏览器或清除网站数据不会自动迁移进度；请使用原来的浏览器，避免隐私窗口。

## 源码与测试

`dist/` 就是可运行的源码和资源，不需要前端构建。`dist/game/` 是当前冒险入口，`dist/fruit-challenge/` 是正式接果子模式。旧 v8、preview、challenge-test 和两套接果子试玩已清理；仅保留当前正式模式、共用资源和存档兼容代码。`engine-classic.js` 保留其他关卡逻辑和旧存档续玩及第 6、8、12 关的分版本规则，`engine-v3.js` 保留更早存档兼容；它们不是独立旧版入口。

- `desktop/Launcher.cs`：Windows 启动器源码。
- `desktop/build.ps1`：使用 Windows .NET Framework 编译器重新生成启动器。
- `tests/`：自动测试与测试用夹具。
- `dist/vendor/`：随包提供的 Three.js 及其 MIT 许可证。

开发者安装 Node.js 后，在仓库根目录运行：

```powershell
npm test
```

没有 npm 依赖，不需要运行 `npm install`。重新编译启动器时运行：

```powershell
powershell -ExecutionPolicy Bypass -File desktop/build.ps1
```
