敲敲岛 · Windows 本地单机版

先完整解压文件夹，再双击「敲敲岛.exe」。不需要联网、登录、安装 Node/Python，或手动运行命令。
游戏会在电脑的默认浏览器中打开，画面和全部关卡资源都来自本机。
请使用支持 WebGL2 的桌面浏览器和实体键盘，切换英文输入。

退出：关闭游戏页面；右下角托盘中右键「敲敲岛 · 本地单机」，选择「退出敲敲岛」即可完全关闭。
再次游玩：重新双击 exe，启动程序会自动准备本地资源。无需开机自启动，不修改系统任务计划。

存档仍保存在常用浏览器中。入口固定为 http://127.0.0.1:4173/ ，沿用之前本机 challenge-test 的进度。
若此前测试用的浏览器不是默认浏览器，请在原来的浏览器打开该地址；不要清除它的网站数据，也不要用隐私窗口。
线上与本机的记录不自动同步。本压缩包不包含你的个人存档；移动文件夹不影响同一电脑、同一浏览器中的记录。
旧预览和旧版本文件已清理，仅保留正式冒险与接果子模式；原来的存档键保留。

请保持 exe 与 dist 文件夹在一起，不要只拖走 exe，也不要在压缩包中直接运行。
若提示 4173 已占用，请先关闭旧测试服务，再打开游戏。启动程序不会强制结束其他程序。
本版依赖 Windows 内置 .NET Framework 4.x 与已有桌面浏览器。未打包 macOS/Linux 版本。
desktop 文件夹中是启动器源码及重建脚本；普通玩家不需要运行它们。
